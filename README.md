# Rock Paper Scissors Game

A simple command-line Rock Paper Scissors game built using Python.

## Features
- Play against the computer
- Random computer choices using Python's `random` module
- Determines wins, losses, and draws
- Input validation for invalid choices

## Technologies Used
- Python
- `random` module
- Conditional statements and dictionaries

## How to Run
1. Install Python 3 if it is not already installed.
2. Download `rock_paper_scissors.py`.
3. Open a terminal in the folder containing the file.
4. Run:

```bash
python rock_paper_scissors.py
```

## Controls
- `r` = Rock
- `p` = Paper
- `s` = Scissors
